# Sổ Riêng – sổ bán hàng trên điện thoại

Sổ bán hàng cho thợ điện, thợ camera, đại lý thiết bị và cửa hàng nhỏ: kho hàng, phiếu nhập/bán, báo giá và hoá đơn bán hàng ra file PDF, công nợ, serial và bảo hành, công trình, lãi lỗ, nhập/xuất file Excel (CSV).

- **Chỉ chạy trên Android** (Android 8 trở lên). Chưa có bản máy tính hay iPhone.
- **Chạy offline**: không cần mạng, không cần tài khoản, dữ liệu nằm trên máy bạn.
- **Dữ liệu được mã hoá**; app tự sao lưu hằng ngày ra thư mục bạn chọn, file sao lưu cũng được mã hoá. Nên chép file sao lưu ra máy tính hoặc Drive.
- **Mỗi máy một bản quyền. Dùng thử miễn phí 2 tháng**, đủ mọi tính năng.
- Hoá đơn trong app là **hoá đơn bán hàng, không phải hoá đơn điện tử**.

## Tải app

- Bản mới nhất: https://github.com/dinhdang175/SoRieng/releases/latest (chọn file `SoRieng-….apk` ở mục Assets)
- Trang giới thiệu và hướng dẫn cài: https://dinhdang175.github.io/SoRieng/
- Đã cài bản cũ: tải bản mới và cài đè lên, không gỡ app, dữ liệu giữ nguyên.
